# 📚 Примеры использования Design System

Этот каталог содержит практические примеры использования компонентов дизайн-системы проекта.

## 📁 Файлы

### [QUICK-REFERENCE.js](QUICK-REFERENCE.js)
**Быстрый справочник** — готовые copy-paste примеры для быстрого внедрения:
- Toast notifications (уведомления)
- Button system (система кнопок)
- Modal dialogs (модальные окна)
- Form validation (валидация форм)
- Loading states (состояния загрузки)
- Dropdowns (выпадающие меню)

### [mobile-animations-examples.js](mobile-animations-examples.js)
**Примеры мобильных анимаций** — интеграция системы анимаций:
- Базовое использование
- Переходы между секциями
- Анимация списков и карточек
- Оптимизация производительности
- Интеграция с роутингом

### [ui-patterns-examples.js](ui-patterns-examples.js)
**Примеры UI-паттернов** — использование всех компонентов:
- Toast уведомления с различными вариантами
- Модальные окна (простые, с формами, подтверждения)
- Валидация форм с кастомными правилами
- Dropdowns и их состояния
- Loading spinners и skeleton screens

## 🚀 Как использовать

1. **Импортируйте нужные компоненты:**
```javascript
import { Toast, Modal } from '../js/ui-patterns.js';
import { mobileAnimations } from '../js/mobile-animations.js';
```

2. **Скопируйте нужный пример** из файлов выше

3. **Адаптируйте под свои нужды** — все примеры хорошо прокомментированы
